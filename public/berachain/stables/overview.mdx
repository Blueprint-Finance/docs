## Dynamic APY calculation



This vault's headline APY is computed dynamically from on-chain accrual
and a recent strategy-performance window. The figure refreshes between
visits and reflects the most recently observed performance rather than a
static target value.

See [Dynamic APY calculation](/concepts/earn/vaults/dynamic-apy-concept#dynamic-apy-calculation) for the inputs and
the way the calculation is derived.







A historical APY chart renders on this vault's page so you can see how
the yield has evolved over time. The chart is independent of the
headline-APY source.
