## PeripheryFactory

Deploys and tracks periphery strategies and position-management-helper (PMH)
        clones. Approves and blocks strategy and PMH implementations, records migration
        paths, and performs batch strategy upgrades.

_UUPS-upgradeable and owned by the protocol; integrators query it to resolve
     registered strategies and their implementations._

### deployStrategy

```solidity
function deployStrategy(uint64 implId, bytes initData) external returns (address proxy)
```

Deploy a strategy as a TransparentUpgradeableProxy.

_The factory is passed as `initialOwner` of the ProxyAdmin, which means
     the factory holds exclusive upgrade authority over the deployed proxy.
     The ProxyAdmin address is deterministically computed from the proxy's
     address (CREATE1 with nonce = 1) and stored for later use by `upgradeStrategy`
     and `deregisterStrategy`._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| implId | uint64 | The registered strategy implementation ID. |
| initData | bytes | ABI-encoded `initialize(...)` call forwarded to the implementation. |

#### Return Values

| Name | Type | Description |
| ---- | ---- | ----------- |
| proxy | address | Address of the deployed strategy proxy. |

### registerStrategy

```solidity
function registerStrategy(address proxy, address proxyAdmin) external
```

Register a strategy proxy that was not deployed by this factory.

_Use this to bring externally-deployed TransparentUpgradeableProxy strategies
     under factory management.  Pass `address(0)` for `proxyAdmin` if the strategy
     is non-upgradeable or upgrade management is not needed.

WARNING: If `proxyAdmin` is non-zero, the factory must already be the owner of
     that ProxyAdmin before calling this function.  If ownership has not been
     transferred, `upgradeStrategy` and `deregisterStrategy` (ProxyAdmin transfer)
     will revert because `ProxyAdmin.upgradeAndCall` / `ProxyAdmin.transferOwnership`
     are guarded by `onlyOwner`.  Transfer ownership with:
         `ProxyAdmin(proxyAdmin).transferOwnership(address(factory))`
     before registering, or pass `address(0)` and update via a subsequent
     `registerStrategy` call once ownership has been accepted._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| proxy | address | Address of the existing strategy proxy. |
| proxyAdmin | address | Address of the ProxyAdmin that controls `proxy`, or address(0). |

### deregisterStrategy

```solidity
function deregisterStrategy(address proxy, address newOwner) external
```

Deregister a strategy and transfer its ProxyAdmin ownership to `newOwner`.

_After this call the strategy is no longer managed by the factory.
     If no ProxyAdmin was recorded (non-upgradeable strategy), the ownership
     transfer is skipped.

     Callable by the factory owner OR any account holding `STRATEGY_ADMIN` on
     the proxy, giving strategy administrators the ability to reclaim their own
     ProxyAdmin without requiring factory-owner intervention._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| proxy | address | Address of the registered strategy proxy. |
| newOwner | address | Address that will receive ownership of the ProxyAdmin. |
