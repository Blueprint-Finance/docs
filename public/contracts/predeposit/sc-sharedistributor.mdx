## ShareDistributor

Destination-chain LayerZero receiver that distributes vault shares to
        users on behalf of a predeposit vault deployed on a different chain.
        Receives cross-chain claim messages and forwards the corresponding
        vault share balance to each recipient.

### MSG_TYPE_CLAIM

```solidity
uint16 MSG_TYPE_CLAIM
```

Message type identifier for a single-user claim payload.

### MSG_TYPE_BATCH_CLAIM

```solidity
uint16 MSG_TYPE_BATCH_CLAIM
```

Message type identifier for a batched multi-user claim payload.

### targetVault

```solidity
address targetVault
```

Address of the vault whose shares this distributor holds and forwards.

### claimedShares

```solidity
mapping(address => uint256) claimedShares
```

Cumulative shares distributed to each user.

_Not using the ERC-7201 pattern as this is an auxiliary short-lived contract._

### SharesDistributed

```solidity
event SharesDistributed(address user, uint256 shares, bytes32 guid)
```

Emitted when shares are distributed to a single user from an incoming claim message.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| user | address | Recipient address. |
| shares | uint256 | Amount of shares transferred. |
| guid | bytes32 | LayerZero message identifier. |

### BatchSharesDistributed

```solidity
event BatchSharesDistributed(address[] users, uint256[] shares, bytes32 guid)
```

Emitted when shares are distributed in a batch claim message.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| users | address[] | Recipient addresses, parallel to `shares`. |
| shares | uint256[] | Amounts of shares transferred, parallel to `users`. |
| guid | bytes32 | LayerZero message identifier. |
