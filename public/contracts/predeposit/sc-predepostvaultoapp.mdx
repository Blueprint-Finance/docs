## PredepostVaultOApp

Standalone OApp contract that lets `ConcretePredepositVaultImpl` send
        cross-chain share-claim messages over LayerZero. Only the authorised
        vault address may invoke the send path.

### MSG_TYPE_CLAIM

```solidity

```

Message type identifier for a single-user claim payload.

### MSG_TYPE_BATCH_CLAIM

```solidity
uint16 MSG_TYPE_BATCH_CLAIM
```

Message type identifier for a batched multi-user claim payload.

### send

```solidity
function send(bytes payload, bytes options, address refundAddress) external payable returns (struct MessagingReceipt receipt)
```

Sends a LayerZero message using the stored destination endpoint ID.
        Only callable by the configured vault. Quotes the fee internally and
        validates that `msg.value` covers it before dispatching.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| payload | bytes | Encoded message payload. |
| options | bytes | LayerZero execution options. |
| refundAddress | address | Address that receives any excess native fee. |

#### Return Values

| Name | Type | Description |
| ---- | ---- | ----------- |
| receipt | struct MessagingReceipt | LayerZero `MessagingReceipt` for the dispatched message. |
