## UserDepositCapHook

Pre-deposit hook that enforces per-user deposit caps for a single vault

_This hook is deployed per vault. It tracks cumulative deposits per user and enforces the configured cap._

### UserDepositLimitExceeded

```solidity
error UserDepositLimitExceeded(address user, uint256 attemptedTotal, uint256 limit)
```

_Reverts on a deposit/mint that would push the receiver's cumulative deposit above the cap._

### InvalidLimit

```solidity
error InvalidLimit(uint256 limit)
```

_Reverts when a configured deposit cap is invalid (e.g. zero)._

### ZeroAddress

```solidity
error ZeroAddress()
```

_Reverts when an address argument is the zero address._

