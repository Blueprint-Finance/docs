## UserDepositCapHook

Pre-deposit hook that enforces a per-user deposit cap for one or more
        vaults. Each vault has its own configurable cap (in asset units). On
        every `preDeposit` / `preMint`, the hook converts the receiver's
        current share balance back to assets via the vault and reverts when
        the cumulative asset value would exceed the configured cap.

### UserDepositLimitExceeded

```solidity
error UserDepositLimitExceeded(address user, uint256 attemptedTotal, uint256 limit)
```

_Fires when a deposit or mint would push the receiver's asset value above the cap._

### InvalidLimit

```solidity
error InvalidLimit(uint256 limit)
```

_Reserved for invalid cap values (not currently emitted by this contract)._

### ZeroAddress

```solidity
error ZeroAddress()
```

_Fires when a zero address is supplied to `setVaultDepositCap`._

### VaultDepositCapSet

```solidity

```

Emitted when the per-user deposit cap for a vault is updated.

#### Parameters

| ---- | ---- | ----------- |
| vault | address | The vault whose cap was changed. |

| newCap | uint256 | New cap value, in asset units. |

_Maps vault address to the cap that applies to each user in that vault._

        Reverts with `UserDepositLimitExceeded` when the deposit would breach the cap.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
