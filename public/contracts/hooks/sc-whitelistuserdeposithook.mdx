## WhitelistUserDepositHook

Hook that extends `UserDepositCapHook` with an explicit allowlist; deposits and mints
        revert unless the caller (sender) is whitelisted, in addition to the per-user cap check.

### NotWhitelisted

```solidity
error NotWhitelisted(address user)
```

_Reverts when a non-whitelisted address attempts to deposit or mint._

### WhitelistSet

```solidity
event WhitelistSet(address user, bool isWhitelisted)
```

Emitted when a user's whitelist status changes.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| user | address | The address whose status changed. |
| isWhitelisted | bool | The new whitelist status (`true` = whitelisted). |

mapping(address => bool) whitelist
