## WhitelistUserDepositHook

Extends `UserDepositCapHook` with an additional whitelist gate. The
        pre-deposit and pre-mint hooks revert when the deposit-initiating
        `sender` is not on the whitelist; otherwise the parent contract's
        per-user deposit cap is then applied.

```solidity
error NotWhitelisted(address user)
```

_Fires when the deposit-initiating sender is not on the whitelist._

### preDeposit

```solidity
function preDeposit(address sender, uint256 assets, address receiver, uint256 totalAssets) public view
```

Pre-deposit hook. Reverts when `sender` is not whitelisted, then
        enforces the parent contract's per-user deposit cap.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| sender | address | The address initiating the deposit at the vault. |
| assets | uint256 | The amount of assets being deposited. |
| receiver | address | The address that will receive the vault shares. |
| totalAssets | uint256 | The total assets in the vault before this deposit. |
