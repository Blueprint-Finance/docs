## ConcreteBridgedStandardVaultImpl

Standard vault implementation that extends `ConcreteStandardVaultImpl` with unbacked-mint
        capability. Serves as the migration target for old vaults during cross-chain migrations
        (or migration from another vault). It allows an initial mint of shares without depositing
        underlying assets; backing assets are expected to be allocated directly on the strategy.
        Once the migration phase ends this vault can itself be migrated to a standard vault.

### unbackedMint

```solidity
function unbackedMint(uint256 shares) external
```

Mints vault shares without depositing any underlying assets, for the initial mint of a migration.

_Caller must hold `VAULT_MANAGER`. Reverts when `shares` is zero, when `totalSupply()` is
     non-zero (only valid as the initial mint), or when deposit limits are still configured.
     No assets are transferred in; the backing for the minted shares is expected to be
     allocated directly on the strategy._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| shares | uint256 | Amount of shares to mint to the caller for later distribution. |
