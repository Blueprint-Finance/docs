## ConcreteBridgedAsyncVaultImpl

Async vault implementation that extends `ConcreteAsyncVaultImpl` with unbacked-mint
        capability, used as the destination of cross-chain vault migrations (typically from a
        predeposit phase). It allows an initial mint of shares without depositing underlying
        assets; the backing assets are expected to be allocated directly to a strategy on this
        chain. Once the migration phase ends the vault can itself be migrated to a standard
        vault. Designed to pair with `ConcretePredepositVaultImpl`.

### unbackedMint

```solidity
function unbackedMint(uint256 shares) external
```

Mints vault shares without depositing any underlying assets, for the initial mint of a migration.

_Caller must hold `VAULT_MANAGER`. Reverts when `shares` is zero, when `totalSupply()` is
     non-zero (only valid as the initial mint), or when deposit limits are still configured.
     No assets are transferred in; the backing for the minted shares is expected to be
     allocated directly on the strategy._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| shares | uint256 | Amount of shares to mint to the caller for later distribution. |
