## ConcreteAsyncVaultImpl

Vault implementation with epoch-based asynchronous withdrawals. Withdrawal
        requests are queued and settled when an epoch closes rather than executed
        immediately against vault liquidity.

_Extends `ConcreteStandardVaultImpl`; users interact with it through a `VaultProxy`._

### closeEpoch

```solidity
function closeEpoch() external virtual
```

Closes the currently open epoch so it can be processed.

_Caller must hold `WITHDRAWAL_MANAGER` and the vault must not be paused. Once closed, no
     additional requests can be added to that epoch; the next `processEpoch` call settles it._

### processEpoch

```solidity
function processEpoch() external virtual
```

Process pending redeem requests for the next unprocessed closed epoch.

_Harvests all strategies first so the locked share price reflects current accounting,
     then computes the share price and reserves the assets required to satisfy the epoch.
     Only callable by accounts with the ALLOCATOR role._

### _executeWithdraw

```solidity
function _executeWithdraw(address caller, address receiver, address owner, uint256 assets, uint256 shares) internal virtual returns (uint256)
```

_Overrides `_executeWithdraw` to implement the async withdrawal pattern.
     Called by the parent's `withdraw()` and `redeem()` after harvest and validation. Instead
     of immediately transferring assets, the request is queued for epoch processing when the
     queue is active; otherwise it falls through to the parent's synchronous behaviour._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| caller | address | Address that initiated the withdrawal (for access control). |
| receiver | address | Address that will eventually receive the withdrawn assets. |
| owner | address | Address whose shares back this request. |
| assets | uint256 | Amount of assets requested at the time of queueing. |
| shares | uint256 | Amount of shares being escrowed in this request. |

#### Return Values

| Name | Type | Description |
| ---- | ---- | ----------- |
| [0] | uint256 | The `assets` value when the request was queued, or the parent's return otherwise. |
