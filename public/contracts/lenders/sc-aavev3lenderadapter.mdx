## AaveV3LenderAdapter

Lender module that brokers supply, withdraw, borrow, and repay operations
        between a Concrete looping strategy and an Aave V3 pool. Holds the strategy's
        collateral and debt positions, exposes price and rate views in WAD/RAY, and
        enforces that only the bound strategy (and optionally the owner for supply/repay)
        can mutate the position.

### DEFAULT_REPAY_RAY_ROUNDING_BUFFER

```solidity
uint256 DEFAULT_REPAY_RAY_ROUNDING_BUFFER
```

Safety buffer added when sizing a full debt repayment.

_Aave-style variable debt is stored in scaled units and converted
     to underlying amounts using ray (1e27) fixed-point arithmetic.
     Conversions between scaled debt and underlying are not perfectly
     invertible due to integer rounding, which can leave a small
     residual debt (1–few minimal units) when repaying an amount
     computed from a quoted balance.
     This buffer intentionally over-sizes the repayment amount to
     guarantee that the entire scaled debt is burned and the position
     can always be fully unwound, without relying on MAX_UINT semantics._

### constructor

```solidity
constructor(address collateralToken_, address borrowToken_, address dataProvider_) public
```

Captures the immutable collateral, borrow, and Aave V3 data provider references.

_Reads the Aave pool and price oracle from the data provider's addresses provider,
     and reverts if any address resolves to zero. Disables initializers on the
     implementation contract._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| collateralToken_ | address | The ERC20 token used as collateral in the Aave V3 pool. |
| borrowToken_ | address | The ERC20 token to borrow against the supplied collateral. |
| dataProvider_ | address | The Aave V3 `IPoolDataProvider` used to resolve the pool,        price oracle, and reserve configuration. |
