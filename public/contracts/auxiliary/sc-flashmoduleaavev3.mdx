## FlashModuleAaveV3

Flash-loan adapter that routes `IFlashModule` requests through Aave V3's
        `flashLoanSimple`. Looping primitives call `flash` to borrow a single token
        for the duration of one transaction; this module forwards the loan, invokes
        the caller's `executeFlash` hook, and pulls back principal plus premium to
        repay Aave atomically.
Pricing helpers (`flashPremiumMaxInWad`, `flashPremiumQuoteInWad`) and
        liquidity inspection (`depthOfFlashLiquidityExact`) read live values from
        the resolved Aave V3 pool and data provider.

### flash

```solidity
function flash(address token, uint256 amount, LoopModality loopModality, bytes data) external returns (bool)
```

Requests a flash loan from Aave V3 on behalf of `msg.sender`.

_Encodes the caller, looping modality, and inner payload into the Aave `params`
     so that `executeOperation` can dispatch the funds back to the requester._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| token | address | The ERC-20 token to flash-borrow. |
| amount | uint256 | The principal amount to borrow. |
| loopModality | LoopModality | Looping modality forwarded to the requester's `executeFlash`. |
| data | bytes | Opaque payload forwarded verbatim to the requester's `executeFlash`. |

#### Return Values

| Name | Type | Description |
| ---- | ---- | ----------- |
| [0] | bool | Always `true` if the flash loan completed; reverts otherwise. |

### executeOperation

```solidity
function executeOperation(address token, uint256 amountInToken, uint256 premiumInToken, address initiator, bytes params) external returns (bool)
```

Aave V3 callback executed inside the flash-loan transaction.

_Transfers the borrowed `amountInToken` to the original requester, invokes
     `ILoopingPrimitive.executeFlash`, then pulls back `amountInToken + premiumInToken`
     and approves the pool to repay. Only callable by the cached Aave pool with this
     contract as initiator._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| token | address | Token that was flash-borrowed. |
| amountInToken | uint256 | Principal received from Aave. |
| premiumInToken | uint256 | Premium owed back to Aave on top of the principal. |
| initiator | address | Address that initiated the flash loan; must equal this contract. |
| params | bytes | ABI-encoded `(address requester, LoopModality loopModality, bytes data)`. |

#### Return Values

| Name | Type | Description |
| ---- | ---- | ----------- |
| [0] | bool | Always `true` on success; reverts otherwise. |

### flashPremiumMaxInWad

```solidity
function flashPremiumMaxInWad(address) public view returns (uint64 premiumInWad, bool premiumDependsOnLiquidity)
```

Returns the maximum flash-loan premium percentage applied by Aave V3.

_The Aave pool premium is a global value, so it does not depend on the requested liquidity._

#### Return Values

| Name | Type | Description |
| ---- | ---- | ----------- |
| premiumInWad | uint64 | Premium percentage scaled to 1e18. |
| premiumDependsOnLiquidity | bool | Always `false` for Aave V3. |
