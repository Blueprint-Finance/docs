## TwoWayFeeSplitter

Auxiliary contract that abstracts away fee splitting between two recipients per
        vault. Each fee type (e.g. management, performance, deposit) gets its own splitter
        instance; the contract is architected as a clonable upgradeable proxy.
Fees accrue as vault shares held by this contract. Anyone may trigger
        `distributeFees` permissionlessly; the call routes the configured fraction to the
        secondary recipient (typically the service provider) and the remainder to the main
        recipient (typically the vault fee recipient).

```solidity
constructor() public
```

Disables initializers on the implementation so only proxies can be initialized.

### distributeFees

```solidity
function distributeFees(address vault) external
```

Permissionlessly distributes the fees accrued for a given vault.
The fee fraction determines the share sent to the secondary recipient: zero
        routes everything to the main recipient, while `BASIS_POINTS_DENOMINATOR` routes
        everything to the secondary recipient. The main fee recipient is typically the
        vault fee recipient, while the secondary recipient is the service provider.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| vault | address | The vault to collect fees for. |

### setFeeSplit

Sets the full fee split for a given vault. The Fee Splitter Owner can set all
        parameters at once. If a split already exists, the previous accrued fees are
        distributed first using the old parameters.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| vault | address | The vault to set the fee split for. |
| feeFractionOfSecondaryRecipient | uint32 | The fraction of the fees going to the secondary recipient. |
| mainRecipient | address | The main recipient (typically the vault fee recipient). |
| secondaryRecipient | address | The secondary recipient (typically the service provider). |
