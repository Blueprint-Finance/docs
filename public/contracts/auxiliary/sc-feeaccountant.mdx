## FeeAccountant

Receives vault share tokens as the fee recipient and allows authorized
        distributors to distribute accumulated fee shares to whitelisted
        recipients in a single call. Deployed behind a UUPS proxy.
The contract is bound to a single ERC-4626 vault at initialization.
        Only whitelisted recipient addresses may receive fee shares. Roles:
        `DEFAULT_ADMIN_ROLE` can grant/revoke roles, manage the recipient
        whitelist, and authorize upgrades. `DISTRIBUTOR_ROLE` can call
        `distributeFeeShares`.

_The contract itself holds vault shares. `distributeFeeShares` transfers
     shares from this contract to each listed recipient while emitting
     per-transfer and aggregate events that include the share price at the
     time of distribution._

### DISTRIBUTOR_ROLE

```solidity
bytes32 DISTRIBUTOR_ROLE
```

Role identifier for accounts permitted to call `distributeFeeShares`.

### vault

```solidity
contract IERC4626 vault
```

The ERC-4626 vault whose share token this contract receives as fees.

### whitelistedRecipients

```solidity
mapping(address => bool) whitelistedRecipients
```

Whitelist of recipient addresses allowed to receive fee shares.

### FeeDistribution

```solidity
event FeeDistribution(address vault, uint256 sharePrice, uint256 totalShares)
```

Emitted once per `distributeFeeShares` call, after every recipient transfer.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| vault | address | The vault whose shares were distributed. |
| sharePrice | uint256 | The vault share price (assets per one full share) at the time of distribution. |
| totalShares | uint256 | The aggregate amount of shares distributed in this call. |

### FeeTransferred

```solidity
event FeeTransferred(address vault, address recipient, uint256 amount)
```

Emitted on every individual fee transfer inside `distributeFeeShares`.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| vault | address | The vault share token transferred. |
| recipient | address | The whitelisted recipient that received the shares. |
| amount | uint256 | The amount of shares transferred to `recipient`. |
