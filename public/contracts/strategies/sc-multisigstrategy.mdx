## MultisigStrategy

Async strategy that forwards deposited assets to a designated multi-signature
        wallet and pulls them back on withdrawal. Used when the underlying position is
        managed off-chain by a multisig that periodically reports accounting changes.
        Does not generate yield on its own; off-chain managers credit/debit the
        strategy through `adjustTotalAssets`.

_Uses EIP-7201 storage layout for upgradeability. Implements `IAsyncAccounting`
     so the vault and an operator can reconcile the strategy's reported value with
     the off-chain position._

### unpauseAndAdjustTotalAssets

```solidity
function unpauseAndAdjustTotalAssets(int256 diff) external
```

Unpauses the strategy and applies an accounting adjustment in one transaction.

_Callable only by `STRATEGY_ADMIN`. Bypasses nonce, threshold, and cooldown
     validation; intended as the admin recovery path after the strategy auto-pauses
     on a rejected operator adjustment._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| diff | int256 | The signed amount of underlying assets to apply to total assets. |

### adjustTotalAssets

```solidity
function adjustTotalAssets(int256 diff, uint256 accountingNonce_) external
```

Operator-initiated accounting adjustment with nonce, threshold, and cooldown validation.

_Callable only by `STRATEGY_ADMIN` or `OPERATOR_ROLE` while the strategy is not paused.
     If the change fails validation the strategy auto-pauses and returns without
     reverting; recovery must go through `unpauseAndAdjustTotalAssets`._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| diff | int256 | The signed amount of underlying assets to apply to total assets. |
| accountingNonce_ | uint256 | The expected next accounting nonce, used to prevent replay        and out-of-order updates. |
