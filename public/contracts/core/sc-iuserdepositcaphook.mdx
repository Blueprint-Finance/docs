## IUserDepositCapHook

Interface for UserDepositCapHook contract

_Exposes hook-specific administrative and view functions_

### UserDepositLimitExceeded

```solidity
error UserDepositLimitExceeded(address user, uint256 attemptedTotal, uint256 limit)
```

_Reverts on a deposit/mint that would push the receiver's cumulative deposit above the cap._

### InvalidLimit

```solidity
error InvalidLimit(uint256 limit)
```

_Reverts when the configured deposit cap is invalid (e.g. zero)._

### ZeroAddress

```solidity
error ZeroAddress()
```

_Reverts when an address argument is the zero address._

### DepositCapSet

```solidity
event DepositCapSet(uint256 oldCap, uint256 newCap)
```

Emitted when the per-user deposit cap is updated.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| oldCap | uint256 | The previous cap value, in asset terms. |
| newCap | uint256 | The new cap value, in asset terms. |

### setDepositCap

```solidity
function setDepositCap(uint256 _depositCap) external
```

Sets the per-user deposit cap for this vault

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| _depositCap | uint256 | The deposit cap for each user (in asset terms) |

### getUserDepositCap

```solidity
function getUserDepositCap() external view returns (uint256)
```

Gets the per-user deposit cap for this vault

#### Return Values

| Name | Type | Description |
| ---- | ---- | ----------- |
| [0] | uint256 | The deposit cap that applies to each user |

### canUserDeposit

```solidity
function canUserDeposit(address _user, uint256 _additionalAssets) external view returns (bool)
```

Checks if a user can deposit a given amount into this vault

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| _user | address | The user (receiver) address |
| _additionalAssets | uint256 | The amount of assets to deposit |

#### Return Values

| Name | Type | Description |
| ---- | ---- | ----------- |
| [0] | bool | Whether the deposit is allowed |
