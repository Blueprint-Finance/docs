## TargetOwnerAmount

     Avoids multiple local address variables in deposit/redeem helpers._

  uint256 expected;

## IPositionHelperBase

Interface for the position helper base contract that mediates leveraged positions on
        behalf of a position owner. Exposes lender operations (supply/withdraw/borrow/repay),
        target-vault deposits and redemption requests, high-level deploy/retract flows,
        flash-loan-assisted self-liquidation, admin configuration and rescue functions.

### retract

```solidity
function retract(uint256 repayAmount, uint256 withdrawalAmount, uint64 maxPermissibleLtv) external
```

Unwind primitive: pull `repayAmount` borrow tokens from positionOwner, repay debt,
        then withdraw `withdrawalAmount` collateral.  The position LTV after the withdrawal
        must not exceed `maxPermissibleLtv`, which itself must not exceed the lender's
        protocol max LTV.  Either amount can be zero.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| repayAmount | uint256 | The borrow tokens to pull from the position owner and repay. |
| withdrawalAmount | uint256 | The collateral amount to withdraw and return to the position owner. |
| maxPermissibleLtv | uint64 | The post-operation LTV ceiling, in wad (1e18 = 100%). |

### calculateTargetRepayAmount

```solidity
function calculateTargetRepayAmount(uint256 requiredPrincipalAmount, uint64 targetLtvInWad) external view returns (uint256 targetRepayAmount)
```

Ideal borrow-token amount to repay in order to withdraw `requiredPrincipalAmount`
        of collateral and land exactly at `targetLtvInWad`.

_Formula: repay = max(0, d - (c - R)*p*targetLtv)
     Returns 0 when the position is already at or below targetLtv after the withdrawal,
     i.e. no repayment is needed.
     Returns the full debt when `requiredPrincipalAmount >= collateral`._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| requiredPrincipalAmount | uint256 | Collateral to be withdrawn, in collateral token units. |
| targetLtvInWad | uint64 | Desired post-operation LTV, in WAD (1e18 = 100%). |

#### Return Values

| Name | Type | Description |
| ---- | ---- | ----------- |
| targetRepayAmount | uint256 | Borrow tokens to repay, in borrow token units. |
