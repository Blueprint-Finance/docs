## PreviewOperationResult

Struct containing preview operation results

```solidity
struct PreviewOperationResult {
  uint256 flashAmount;
  uint256 pairedTokenAmount;
  uint256 floatingAmount;
  uint256 collateralDiff;
  uint256 debtDiff;
  uint256 positionEquityBeforeOperation;
  uint256 positionEquityAfterOperation;
  int256 maximumLoss;
  uint64 flashPremiumQuoteInWad;
  enum LeverageOperation operation;
}
```

## LenderModuleState

Complete state of a lender module including position and configuration

```solidity
struct LenderModuleState {
  address collateralToken;
  address borrowToken;
  uint256 collateralAmount;
  uint256 debtAmount;
  uint256 collateralBalance;
  uint64 currentLtvInWad;
  bool hasFunds;
}
```

## PreviewOperationFlags

Flags indicating the type and context of a preview operation

_Combined into a single struct to avoid stack-too-deep in operation previews_

```solidity
struct PreviewOperationFlags {
  bool isAllocation;
  bool isUserWithdraw;
}
```

## PreviewOperationParams

Parameters for previewing an operation

```solidity
struct PreviewOperationParams {
  uint256 allocOrDeallocAmount;
  bool isAllocation;
  uint64 maxSlippageInWad;
  uint64 targetLtvInWad;
}
```

## IBaseLoopingStrategy

Shared interface for looping strategy implementations exposing leverage adjustment,
        position previewing, looping configuration, module wiring, and emergency rescue.

### previewOperation

```solidity
function previewOperation(uint256 requestedAmount, bool isAllocation, uint64 targetLtvInWad, uint64 maxSlippageInWad) external view returns (struct PreviewOperationResult result, bool ltvUpperBoundReached, bool deallocationHigherThanEquity, bool insufficientFlashLiquidity)
```

Previews an allocation or deallocation operation without executing it

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| requestedAmount | uint256 | Amount to allocate or deallocate |
| isAllocation | bool | True for allocation, false for deallocation |
| targetLtvInWad | uint64 | Target loan-to-value ratio in wad (1e18) |
| maxSlippageInWad | uint64 | Maximum acceptable slippage in wad (1e18) |

#### Return Values

| Name | Type | Description |
| ---- | ---- | ----------- |
| result | struct PreviewOperationResult | Preview operation result containing all operation details |
| ltvUpperBoundReached | bool | Whether target LTV exceeds upper bound |
| deallocationHigherThanEquity | bool | Whether deallocation exceeds equity |
| insufficientFlashLiquidity | bool | Whether flash liquidity is insufficient |
