## Hooks

_Hook configuration recorded by the vault: the target contract implementing `IHook`
     and a flag bitfield indicating which of the pre/post hooks the target wishes to receive._

```solidity
struct Hooks {
  address target;
  uint96 flags;
}
```

## IHook

Optional pre/post action hook surface invoked by the vault around deposit, mint,
        withdraw, and redeem operations.

_Hook contracts are registered via `setHooks` on the vault. Each call carries the
     pre-operation `totalAssets` of the vault so hooks can perform supply/price checks
     without recomputing it. Hooks may revert to block the underlying ERC-4626 operation._

### preDeposit

```solidity
function preDeposit(address sender, uint256 assets, address receiver, uint256 totalAssets) external
```

Invoked before a deposit is executed.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| sender | address | The caller initiating the deposit. |
| assets | uint256 | The asset amount being deposited. |
| receiver | address | The address that will receive the minted shares. |
| totalAssets | uint256 | The vault's `totalAssets()` evaluated before the deposit. |
