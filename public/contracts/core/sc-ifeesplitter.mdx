## ITwoWayFeeSplitter

Interface for a fee splitter that distributes collected fees between a main and a
        secondary recipient per vault, according to a configurable fee fraction.

### TwoWayFeeSplit

_The fee split configuration for a given vault.
     The secondary recipient receives the fraction of collected fees defined by
     `feeFractionOfSecondaryRecipient`; the main recipient receives the remainder.
     For instance, with a fee fraction of 250 (2.5% in basis points), the secondary
     recipient gets 2.5% of fees and the main recipient gets 97.5%._

```solidity
struct TwoWayFeeSplit {
  uint32 feeFractionOfSecondaryRecipient;
  address mainRecipient;
  address secondaryRecipient;
  bool set;
}
```

### TwoWayFeeSplitterStorage

_Storage layout of the fee splitter contract._

```solidity
struct TwoWayFeeSplitterStorage {
  uint8 feeType;
  mapping(address => struct ITwoWayFeeSplitter.TwoWayFeeSplit) feeSplit;
  mapping(address => uint256) distributedFees;
}
```

### InvalidFeeSplit

```solidity
error InvalidFeeSplit(uint32 feeFractionOfSecondaryRecipient, address mainRecipient, address secondaryRecipient)
```

_Thrown when an attempted fee split configuration would cause a `collectFees` call to revert
     (e.g. zero recipient with a non-zero share, or fraction out of bounds)._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| feeFractionOfSecondaryRecipient | uint32 | The offending fee fraction of the secondary recipient. |
| mainRecipient | address | The offending main recipient address. |
| secondaryRecipient | address | The offending secondary recipient address. |

### VaultInvalidOrWIthInvalidFeeSplit

```solidity
error VaultInvalidOrWIthInvalidFeeSplit(address vault)
```

_Thrown when a fee split lookup is performed for an address with no fee split registered.
     The identifier name is intentionally preserved despite the casing typo to avoid breaking ABIs._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| vault | address | The vault address that has no valid fee split. |

### FeeFractionOutOfBounds

```solidity
error FeeFractionOutOfBounds()
```

_Thrown when the fee fraction provided is outside the accepted range (0..BASIS_POINTS_MAX)._

### FeesDistributed

```solidity

```

Emitted when fees are collected and distributed for a given vault.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| vault | address | The vault that the fees are collected for. |
| fee1Amount | uint256 | The amount of fees credited to the main recipient. |
| fee2Amount | uint256 | The amount of fees credited to the secondary recipient. |
| recipient1 | address | The main recipient of the fees. |
| recipient2 | address | The secondary recipient of the fees. |
