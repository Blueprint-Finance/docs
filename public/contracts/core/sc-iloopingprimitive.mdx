### ExecuteFlash

```solidity
event ExecuteFlash(LoopModality loopModality, uint256 flashAmount, uint256 flashPremiumAmount, uint256 pairedTokenAmount, uint256 floatingAmount, uint256 floatingAmountUnused)
```

Emitted when a flash-driven looping operation finishes.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| loopModality | LoopModality | The loop modality of the executed operation. |
| flashAmount | uint256 | The amount that was flash borrowed. |
| flashPremiumAmount | uint256 | The premium paid on the flash loan. |
| pairedTokenAmount | uint256 | The amount of the paired token involved in the operation. |
| floatingAmount | uint256 | The amount of principal tokens added to reduce the flash amount. |
| floatingAmountUnused | uint256 | The portion of the floating amount that was not consumed by the operation. |

### executeFlash

```solidity
function executeFlash(address token, uint256 amountInToken, uint256 premiumInToken, address requester, LoopModality loopModality, bytes data) external returns (bool)
```

Callback invoked by the flash module to execute the looping operation.

_Only the registered flash module may call this, and the requester must be this contract._

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| token | address | The address of the flash-borrowed token. |
| amountInToken | uint256 | The amount of `token` that was flash borrowed. |
| premiumInToken | uint256 | The premium owed on top of `amountInToken`. |
| requester | address | The address that initiated the flash (must equal this contract). |
| loopModality | LoopModality | The loop modality identifying which operation to perform. |
| data | bytes | ABI-encoded operation payload (paired token, paired amount, floating amount). |

#### Return Values

| Name | Type | Description |
| ---- | ---- | ----------- |
| [0] | bool | True when the operation executed successfully. |
