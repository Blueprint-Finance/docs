## ILenderModule

Interface for lender module adapters that wrap an external lending market
        (e.g. Aave V3, Morpho) and expose a unified API for supply, withdraw, borrow,
        and repay, plus the read-side data required by looping strategies.

### supply

```solidity
function supply(uint256 amount) external
```

Supplies `amount` of collateral token to the underlying lender.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| amount | uint256 | The amount of collateral token to supply. |

### withdraw

```solidity
function withdraw(uint256 amount) external
```

Withdraws `amount` of collateral token from the underlying lender.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| amount | uint256 | The amount of collateral token to withdraw. |

### borrow

| ---- | ---- | ----------- |

| debtAmount | uint256 | The amount of debt currently borrowed. |

### getFullPosition

```solidity
function getFullPosition() external view returns (uint256 collateralAmount, uint256 debtAmount, uint64 currentLtvInWad, uint256 collateralPriceInRay)
```

Returns the full position state including current LTV and collateral price.

#### Return Values

| Name | Type | Description |
| ---- | ---- | ----------- |
| collateralAmount | uint256 | The amount of collateral currently supplied. |
| debtAmount | uint256 | The amount of debt currently borrowed. |
| currentLtvInWad | uint64 | The current loan-to-value ratio in wad (1e18 = 100%). |
| collateralPriceInRay | uint256 | The collateral price denominated in the borrow token, in ray (1e27). |
