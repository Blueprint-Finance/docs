## IPredepostVaultOApp

Interface for the predeposit vault's LayerZero OApp adapter.
        Exposes send and fee-quote functions used by an authorized vault to dispatch
        cross-chain messages (e.g. claim notifications) via LayerZero, plus the configured
        destination endpoint setter and getter.

_Package references such as `@layerzerolabs/lz-evm-protocol-v2/...` are import paths, not NatSpec tags._

### send

```solidity
function send(bytes payload, bytes options, address refundAddress) external payable returns (struct MessagingReceipt receipt)
```

Send a LayerZero message (only callable by vault)

_Quotes the fee internally and validates msg.value is sufficient
Uses the stored dstEid_

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| payload | bytes | Message payload |
| options | bytes | LayerZero options |
| refundAddress | address | Address to refund excess fee |

#### Return Values

| Name | Type | Description |
| ---- | ---- | ----------- |
| receipt | struct MessagingReceipt | The LayerZero messaging receipt for the dispatched message. |
