## PositionHelperAaveV3

Concrete, clonable implementation of `PositionHelperBase` that
        integrates Aave V3 as the lender. Each clone manages one leveraged
        supply/borrow position on behalf of a single `positionOwner`.

_Clone lifecycle:
  1. Deploy this implementation once with Aave infrastructure addresses.
     The constructor calls `_disableInitializers()` — the bare implementation
     cannot be used directly and is intended for cloning only.
  2. For each position, deploy a clone using `ClonesWithImmutableArgs.clone`
     with the same immutable-arg encoding as `PositionHelperBase` (62 bytes):
       `[positionOwner (20)][collateralToken (20)][borrowToken (20)]`
       `[collateralDecimals (1)][borrowDecimals (1)]`
     i.e. `abi.encodePacked(positionOwner, collateralToken, borrowToken, collateralDecimals, borrowDecimals)`.
  3. Call `initialize(...)` on the clone to set per-position state.

Pre-approved allowances set in `initialize` (no per-call approvals needed):
  • collateralToken → pool        : MAX  (supply)
  • collateralToken → swapModule  : MAX  (self-liq swap)
  • borrowToken     → pool        : MAX  (repay)
  • borrowToken     → target      : MAX  (depositOnTarget)
  • borrowToken     → flashModule : MAX  (flash repayment)
  • yieldVault shares → yieldVault: MAX  (only relevant if the helper ever holds vault shares)

Required positionOwner approvals (one-time setup):
  | Operation           | Token                       | Mechanism                        |
  |---------------------|-----------------------------|----------------------------------|
  | supply              | collateralToken             | approve(helper, MAX)             |
  | withdraw / selfLiq  | aToken (collateral reserve) | approve(helper, MAX)             |
  | borrow              | debtToken (var or stable)   | approveDelegation(helper, MAX)   |
  | repay               | borrowToken                 | approve(helper, MAX)             |
  | requestRedemption   | target vault shares         | approve(helper, MAX)             |
  | cancelRedemption /  |                             | helper must hold                 |
  | claimRedemption     | —                           | WITHDRAWAL_MANAGER_ROLE on vault |_

### initialize

```solidity
function initialize(address admin_, address operator_, address yieldVault_, address flashModule_, address swapModule_, uint64 healthyLtvInWad_, uint64 healthyLtvDeviationInWad_, uint64 selfLiqThrBufferInWad_) external
```

Initializes a freshly cloned instance. Must be called exactly once.

#### Parameters

| Name | Type | Description |
| ---- | ---- | ----------- |
| admin_ | address | Address granted `POSITION_ADMIN_ROLE`. |
| operator_ | address | Address granted `POSITION_OPERATOR_ROLE`. |

| flashModule_ | address | Flash loan module address (IFlashModule). |
| swapModule_ | address | Swap module address (ISwapModule). |
| healthyLtvInWad_ | uint64 | Centre of the desired healthy LTV band, in WAD (1e18 = 100%). |
| healthyLtvDeviationInWad_ | uint64 | Half-width of the healthy LTV band, in WAD. Must be > 0. |
| selfLiqThrBufferInWad_ | uint64 | WAD buffer below liq threshold that triggers self-liq. Must be > 0. |
